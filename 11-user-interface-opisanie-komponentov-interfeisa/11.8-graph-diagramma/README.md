# 11.8 GRAPH (Диаграмма)

## 11.8.1. General structure

**GRAPH** описывает график, используемый для отображения данных устройства в приложении EDD. **GRAPH** предназначен для отображения статического набора данных, в отличие от **CHART**, который используется для отображения непрерывно собираемых значений данных с устройства.

Серии данных могут храниться в виде массива или списка в устройстве или могут быть данными, хранящимися от имени устройства приложением EDD с использованием конструкции **FILE**. В любом случае, график может указывать одну или несколько **WAVEFORM** для отображения в приложении EDD.

Каждый **MEMBER** должен иметь имя и ссылку на **WAVEFORM**. Описание и справочная информация являются необязательными строками и, если присутствуют, используются для создания легенды графика **GRAPH** и контекстной справки о **WAVEFORM**. Если они отсутствуют, для этой цели следует использовать **LABEL** и **HELP** для **WAVEFORM**.

Когда приложение EDD начинает отображать **GRAPH**, запускаются и выполняются указанные **INIT\_ACTIONS** и **REFRESH\_ACTIONS** для **WAVEFORM**. Затем каждая серия данных отображается на графике. Приложение EDD позволяет пользователю увеличивать масштаб графика **GRAPH** для изучения конкретных областей интереса. При этом устанавливаются новые значения **VIEW\_MIN** и **VIEW\_MAX** для оси **AXIS**, и вызываются **REFRESH\_ACTIONS**, позволяя EDD при необходимости управлять или обновлять данные.

Приложение EDD также должно позволять пользователю перемещать область отображения графика (панорамирование). Панорамирование и масштабирование не ограничены какими-либо пределами. Для удобства пользователя должна быть доступна легенда, поясняющая формы сигналов, а также подписи и коды единиц измерения для осей.

Для построения легенд и справочной информации о кривых приложение EDD должно поддерживать следующие правила.

* Приложение EDD должно отображать описание (если оно определено в элементах GRAPH) в качестве легенды. Если описание не определено, приложение EDD должно использовать LABEL указанной WAVEFORM. Пустая строка считается определенной строкой.
* Приложение EDD должно предоставлять пользователю справочную информацию о элементах GRAPH. Если атрибут HELP для элементов GRAPH отсутствует, должна использоваться справочная информация WAVEFORMs.
* Если LABEL/HELP WAVEFORM не определен (или является пустой строкой), метка/справка в легенде должна отображаться с использованием описания/справки элемента WAVEFORM.
* Если описание/справка элемента WAVEFORM не определено (или является пустой строкой), метка/справка в легенде должна отображаться пустой строкой (т.е. быть пустой).
* Все легенды должны быть читаемыми.

Приложение EDD должно объединять WAVEFORMs, ссылающиеся на одну и ту же Y\_AXIS. Кривые должны отображаться вместе в области графика, и только одна ось Y должна показываться сбоку от области графика.

Если данные WAVEFORM относятся к CLASS DYNAMIC, GRAPH должен периодически обновляться.

Атрибут HANDLING WAVEFORM определяет, может ли пользователь редактировать форму сигнала. При закрытии GRAPH должны вызываться EXIT\_ACTIONS, чтобы позволить EDD получить доступ к отредактированным WAVEFORMs и управлять ими. Приложение EDD должно предоставлять механизм для изменения формы сигнала пользователем (прямое перетаскивание и клик, ввод в таблицу и т.д.) и механизм для указания завершения редактирования.

Для GRAPH с определением CYCLE\_TIME приложение EDD должно приостанавливать чтение значений с устройства во время редактирования графика.

POST\_EDIT\_ACTIONS для VARIABLES должны вызываться при каждом изменении формы сигнала графика. Это позволяет проверять вводимые данные и при необходимости изменять их в зависимости от внесенных изменений.

**Ссылки на элементы**\
Элементы могут быть доступны из других частей EDD через идентификатор GRAPH и имя MEMBER с использованием точечной нотации:

```
graph-identifier.member-name
```

**Цвет фона**\
Фоновый цвет отображения GRAPH определяется приложением EDD. Для обеспечения единообразия цвет фона по умолчанию должен быть **БЕЛЫМ (WHITE)**. Приложение EDD должно поддерживать одновременное отображение как минимум шести кривых.

## 11.8.2 CYCLE\_TIME

**Атрибут CYCLE\_TIME** определяет временной интервал (в миллисекундах), через который приложение EDD должно повторно считывать значения источников с устройства. График **GRAPH** обновляется (и вызываются **REFRESH\_ACTIONS**) с периодичностью, заданной атрибутом **CYCLE\_TIME**.

**Примечание:** Из-за особенностей производительности приложения EDD (например, задержек при мультиплексированном вводе-выводе) фактическое время цикла может варьироваться из-за изменений скорости обновления, задержек и джиттера.

По умолчанию, для **GRAPH** не задан цикл обновления. В этом случае **CYCLE\_TIME** по умолчанию равен:

* **Профили связи:** CS, GPE, HART, PB, PN\
  **Значение по умолчанию:**\
  +бесконечность (т.е. GRAPH не обновляется периодически)- неправда!!
* **Профили связи:** FF, ISA100\
  **Значение по умолчанию:**\
  1 000 миллисекунд

**Примечание:** Невозможно полностью отключить обновление GRAPH, но можно установить CYCLE\_TIME на максимально возможное значение, чтобы минимизировать частоту обновлений.

В остальных случаях CYCLE\_TIME должно быть положительным значением. Хотя CYCLE\_TIME может ссылаться на VARIABLE, приложение EDD должно сохранять значение CYCLE\_TIME неизменным на протяжении всего времени отображения GRAPH. Значение CYCLE\_TIME определяется сразу после выполнения INIT\_ACTIONS, но до отображения GRAPH.

Значение CYCLE\_TIME остается фиксированным, пока GRAPH отображается. Если GRAPH закрыть и снова открыть, он может получить новое значение CYCLE\_TIME.

{% code title="Lexical structure" %}
```c
CYCLE_TIME integer-expression | integer-expression <cond>;
```
{% endcode %}

## 11.8.3 X\_AXIS

**Атрибут X\_AXIS** определяет способ отображения оси X. Каждый **WAVEFORM** на **GRAPH** использует общую **X\_AXIS**, но может иметь собственную **Y\_AXIS** или использовать общую ось Y. По умолчанию, если атрибут **X\_AXIS** не указан, отображение оси X определяется на основе данных **WAVEFORMS** в **GRAPH**.

{% code title="Lexical structure" %}
```c
X_AXIS reference | reference <cond>;
```
{% endcode %}

Описание атрибутов представлено ниже
