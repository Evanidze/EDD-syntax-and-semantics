# 11.9 WAVEFORM (Форма волны)

## 11.9.1 General structure

**WAVEFORM** описывает набор данных, который может отображаться на **GRAPH**. **WAVEFORM** представляет собой вектор или последовательность данных, описанных как:

* Пары значений X-Y
* Последовательность Y-значений с равными интервалами по горизонтали (т.е. временной ряд Y-T)
* Горизонтальную или вертикальную линию

Помимо предоставления самих данных формы сигнала, ключевые точки в ряду данных могут быть выделены.

Если список действий (**ACTIONS**) для **WAVEFORM** является условным, могут возникать непредвиденные результаты, если условная логика вызывает изменение списка **ACTIONS** во время их выполнения.

{% code title="Lexical structure" %}
```c
WAVEFORM identifier {
    LABEL string-value;
    HELP string-value;
    EMPHASIS boolean-specifier;
    EXIT_ACTIONS {actions-specifier}
    HANDLING handling-specifier;
    INIT_ACTIONS {actions-specifier}
    KEY_POINTS {
        X_VALUES {key-points-specifier}
        Y_VALUES {key-points-specifier}
    }
    LINE_COLOR line-color-specifier;
    LINE_TYPE line-type-specifier;
    REFRESH_ACTIONS {actions-specifier}
    TYPE waveform-type-specifier;
    VALIDITY boolean-specifier;
    VISIBLITY boolean-specifier;
    Y_AXIS [reference | reference<cond>];
}
```
{% endcode %}

Для **WAVEFORMs**, в которых не указаны **LINE\_TYPE** или **LINE\_COLOR**, каждая линия должна визуально отличаться от других линий на **GRAPH**.

## 11.9.2 EXIT\_ACTIONS

**Атрибут EXIT\_ACTIONS** определяет **METHODS**, которые выполняются при закрытии **GRAPH**, содержащего **WAVEFORM**. EXIT\_ACTIONS позволяют захватывать и обрабатывать отредактированные данные waveform по необходимости EDD. Также, если устройству требуется специальный режим для предоставления данных waveform, EXIT\_ACTION может быть использован для сброса этого режима при закрытии графика.

Указанные **METHODS** выполняются в порядке их объявления. Если выполнение **METHOD** прерывается по незапланированной причине, оставшиеся **METHODS** не выполняются.

Если **INIT\_ACTIONS** для **WAVEFORM** были прерваны, **EXIT\_ACTIONS** не активируются.

{% code title="Lexical structure" overflow="wrap" %}
```c
EXIT_ACTIONS {actions-specifier}
actions-specifier := [reference<cond> [, reference<cond>] *] ? [DEFINITION {compound-statement}]<cond>?
```
{% endcode %}

Описание атрибутов приведено в таблице 108.

## 11.9.3 INIT\_ACTIONS

**Атрибут INIT\_ACTIONS** определяет методы (METHODs), которые выполняются перед первым отображением WAVEFORM на GRAPH. INIT\_ACTIONS запускаются один раз и не выполняются снова, пока содержащий WAVEFORM график GRAPH не будет закрыт и открыт заново. Эта конструкция может использоваться для первоначального чтения WAVEFORM с устройства или из FILE, а также для любой необходимой предварительной обработки (например, усреднения или фильтрации данных), которая выполняется перед отображением.

Указанные METHODS выполняются в порядке их объявления. Если выполнение METHOD завершается по незапланированной причине, оставшиеся METHODS не выполняются. Кроме того, приложение EDD не будет отображать WAVEFORM, если выполнение METHOD завершится по незапланированной причине.

Независимо от того, отображаются ли какие-либо формы сигналов, график GRAPH будет отображен (то есть график может быть пустым).

{% code title="Lexical structure" overflow="wrap" %}
```c
INIT_ACTIONS {actions-specifier}
actions-specifier := [reference<cond> [, reference<cond>] *] ? [DEFINITION {compound-statement}]<cond>?
```
{% endcode %}

Описание атрибутов приведено в таблице 108.

<p align="center">Таблица 108</p>

| Тип значения | Описание                                                               |
| ------------ | ---------------------------------------------------------------------- |
| reference    | Ссылка на экземпляр METHOD или экземпляр METHOD с аргументами.         |
| DEFINITION   | Профили связи: CS, GPE, PB, PN. Лексический элемент (см. раздел 14.4). |

## 11.9.4 KEY\_POINTS

### 11.9.4.1 General structure

**Атрибут KEY\_POINTS** определяет ключевые точки в **WAVEFORM**, которые должны быть выделены приложением EDD. Эти ключевые точки не обязательно должны напрямую соответствовать точкам данных, указанным через атрибут **TYPE**.

Способ выделения этих точек определяется приложением EDD. По умолчанию, если атрибут **KEY\_POINTS** не указан, ни одна из точек **WAVEFORM** не должна выделяться.

{% code title="Lexical structure" overflow="wrap" %}
```c
KEY_POINTS {
    X_VALUES {values-specifier}
    Y_VALUES {values-specifier}
}
```
{% endcode %}

### 11.9.4.2 X\_VALUES / Y\_VALUES

{% code title="Lexical structure" overflow="wrap" %}
```c
X_VALUES {values-specifier}
Y_VALUES {values-specifier}
value-specifier := [reference | double-constant | float-constant | integer-constant | unsigned-integer-constant]+
```
{% endcode %}

Описание атрибутов приведено в таблице ниже.

<table><thead><tr><th width="152">Тип значения</th><th>Описание</th></tr></thead><tbody><tr><td>reference</td><td>Ссылка на экземпляр VARIABLE, элемент экземпляра RECORD, элемент экземпляра VALUE_ARRAY, элемент экземпляра REFERENCE_ARRAY, либо на экземпляр VALUE_ARRAY или REFERENCE_ARRAY.</td></tr><tr><td>double</td><td>Константа с плавающей точкой двойной точности.</td></tr><tr><td>float</td><td>Константа с плавающей точкой одинарной точности.</td></tr><tr><td>integer</td><td>Целочисленная константа.</td></tr><tr><td>unsigned_integer</td><td>Целочисленная константа без знака.</td></tr></tbody></table>

## 11.9.5 REFRESH\_ACTIONS

**Атрибут REFRESH\_ACTIONS** определяет **METHODS**, которые выполняются:

* Перед первым отображением **WAVEFORM**
* При изменениях, связанных с **X\_AXIS** или **Y\_AXIS** (панорамирование или масштабирование)
* При каждом истечении **CYCLE\_TIME**, если он определен в **GRAPH**

Внутри метода видимая область может быть рассчитана и установлена на оси с помощью **VIEW\_MIN** и **VIEW\_MAX**. Все **WAVEFORMs**, связанные с одной и той же **AXIS**, должны отображаться в одной и той же области на **GRAPH**.

Указанные **METHODS** выполняются в порядке их объявления. Если **METHOD** завершается по незапланированной причине:

* Оставшиеся **METHODS** не выполняются
* Приложение EDD восстанавливает исходные значения **X\_VALUES** и **Y\_VALUES** для **WAVEFORM**
* **WAVEFORM** не отображается на **GRAPH**

При истечении **CYCLE\_TIME** или действиях пользователя (панорамирование/масштабирование) **REFRESH\_ACTIONS** запускаются снова. При успешном выполнении **REFRESH\_ACTIONS** **WAVEFORM** снова отображается на **GRAPH**.

**GRAPH** отображается в любом случае, даже если он пустой (не содержит waveform).

Следует избегать встраивания пользовательских интерфейсов в **REFRESH\_ACTIONS METHODS**, поскольку частые обновления могут вызывать значительные помехи в работе.

При панорамировании/масштабировании **REFRESH\_ACTIONS** могут запускаться только после серии последовательных операций, а не после каждой отдельной операции. После выполнения **REFRESH\_ACTIONS**, вызванных панорамированием/масштабированием, приложение EDD может сбросить таймер **CYCLE\_TIME**.

**Профили связи: HART**

{% hint style="info" %}
**REFRESH\_ACTIONS** переменных (**VARIABLES**), на которые ссылается **WAVEFORM** (через **KEY\_POINTS**), не должны активироваться при обновлении **WAVEFORM**.
{% endhint %}

{% code title="Lexical structure" overflow="wrap" %}
```c
REFRESH_ACTIONS { [actions-specifier [, actions-specifier]*] }
actions-specifier := [reference<cond> [, reference<cond>]*] | [DEFINITION { compound-statement }]<cond>
```
{% endcode %}

Описания атрибутов содержатся в таблице 108

## 11.9.6 TYPE

### 11.9.6.1 General structure

**Атрибут TYPE** определяет тип данных, содержащихся в **WAVEFORM**.

{% code title="Lexical structure" %}
```c
TYPE waveform-type-specifier;
waveform-type-specifier := [XY | YT | HORIZONTAL | VERTICAL ]
```
{% endcode %}

### 11.9.6.2 XY

**Атрибут XY** определяет **WAVEFORM**, содержащий список точек (x,y). Тип **XY WAVEFORM** позволяет отображать произвольный набор точек данных, при этом данные не обязательно должны быть равномерно распределены.

{% code title="Lexical structure" %}
```c
XY {
    X_VALUES {values-specifier}
    Y_VALUES {values-specifier}
    NUMBER_OF_POINTS integer-expression<cond>;
}
```
{% endcode %}

Описание атрибутов XY приведено ниже.

<table><thead><tr><th width="198">Атрибут</th><th>Описание</th></tr></thead><tbody><tr><td>X_VALUES</td><td>Определяет X-координату каждой точки WAVEFORM. Для каждой X-координаты в X_VALUES должна существовать соответствующая Y-координата в Y_VALUES. Атрибут X_VALUES описан в разделе 11.9.4.2.</td></tr><tr><td>Y_VALUES</td><td>Определяет Y-координату каждой точки WAVEFORM. Для каждой Y-координаты в Y_VALUES должна существовать соответствующая X-координата в X_VALUES. Атрибут Y_VALUES описан в разделе 11.9.4.2.</td></tr><tr><td>NUMBER_OF_POINTS</td><td>Определяет количество действительных точек данных в X_VALUES и Y_VALUES. Часто серия данных представляет набор выборок, полученных устройством. В зависимости от конфигурации и текущего состояния устройства количество точек может варьироваться. Приложение EDD не должно отображать больше точек, чем указано в атрибуте NUMBER_OF_POINTS. По умолчанию, если атрибут NUMBER_OF_POINTS не указан, количество точек равно размеру X_VALUES и Y_VALUES.</td></tr></tbody></table>

### 11.9.6.3 YT

**Атрибут YT** определяет **WAVEFORM**, который содержит список точек, определенных через начальную X-координату, X-инкремент между последовательными точками и список значений Y. Тип **YT WAVEFORM** позволяет отображать равномерно распределенный или дискретизированный набор данных.

Тип **YT WAVEFORM** должен включать атрибуты **X\_INITIAL**, **X\_INCREMENT** и **Y\_VALUES**. Y-координата каждой точки данных указывается в списке **Y\_VALUES**. Соответствующая X-координата вычисляется с использованием **X\_INITIAL**, **X\_INCREMENT** и смещения (индекса) в списке **Y\_VALUES**. Другими словами, координаты i-й точки данных можно вычислить:

```
y-coordinate = Y_VALUES[i];
x-coordinate = X_INITIAL + (X_INCREMENT * i);
```

{% code title="Lexical structure" overflow="wrap" %}
```c
YT {
    X_INITIAL [reference | double-expression | float-expression | integer-expression | unsigned-integer-expression]<cond>;
    X_INCREMENT [reference | double-expression | float-expression | integer-expression | unsigned-integer-expression]<cond>;
    Y_VALUES {values-specifier}
    NUMBER_OF_POINTS integer-expression<cond>;
}
```
{% endcode %}

Описание атрибутов приведено в таблице ниже.

<table><thead><tr><th width="199">Атрибут</th><th>Описание</th></tr></thead><tbody><tr><td>X_INITIAL</td><td>Определяет X-координату первой точки в WAVEFORM. Ссылка может указывать на экземпляр VARIABLE, элемент RECORD, элемент VALUE_ARRAY или элемент REFERENCE_ARRAY.</td></tr><tr><td>X_INCREMENT</td><td>Задает разницу между X-координатами соседних точек в WAVEFORM. Ссылка может указывать на экземпляр VARIABLE, элемент RECORD, элемент VALUE_ARRAY или элемент REFERENCE_ARRAY.</td></tr><tr><td>Y_VALUES</td><td>Определяет Y-координаты каждой точки в WAVEFORM. Атрибут Y_VALUES описан в разделе 11.9.4.2.</td></tr><tr><td>NUMBER_OF_POINTS</td><td>Указывает количество действительных точек данных в X_VALUES. Часто набор данных представляет выборку, полученную от устройства. В зависимости от конфигурации и текущего состояния устройства количество точек может варьироваться. Приложения EDD не должны отображать больше точек, чем указано в атрибуте NUMBER_OF_POINTS. По умолчанию (если атрибут не задан) количество точек равно размеру X_VALUES.</td></tr></tbody></table>

{% endcode %}

## 11.9.7 Y\_AXIS

**Атрибут Y\_AXIS** определяет способ отображения Y-оси для **WAVEFORM**. Каждый **WAVEFORM** на **GRAPH** использует общую **X\_AXIS**, но имеет собственную **Y\_AXIS**.

По умолчанию, если атрибут **Y\_AXIS** не указан:

* Отображение Y-оси **GRAPH** определяется на основе данных в **WAVEFORM**
* Минимальное и максимальное значения устанавливаются так, чтобы отображались все данные
* Если в **GRAPH** добавляются данные за пределами текущего диапазона оси, значения минимума/максимума автоматически изменяются

{% code title="Lexical structure" %}
```c
Y_AXIS [reference | reference<cond>];
```
{% endcode %}

Описание атрибутов представлено в таблице ниже.

Ссылка на экземпляр AXIS.</td></tr><tr><td>reference&#x3C;cond></td><td>Профили связи: CS, FF, GPE, ISA100, PB, PN. Ссылка на экземпляр AXIS (может быть задана условно).</td></tr></tbody></table>
