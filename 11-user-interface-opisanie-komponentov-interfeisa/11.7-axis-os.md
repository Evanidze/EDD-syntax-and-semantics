# 11.7 AXIS (Ось)

## 11.7.1 General structure

**AXIS** описывает ось для **CHART** или **GRAPH**, определяя систему координат для построения и интерпретации данных. Соответственно, атрибуты **MIN\_VALUE**, **MAX\_VALUE**, **SCALING** и **CONSTANT\_UNIT**, связанные с **AXIS**, являются важными характеристиками.

Ось является необязательной, и если она не объявлена, **GRAPH** или **CHART** автоматически определяют минимальное и максимальное значения оси. Если ось не указана, автоматически генерируемые минимальное и максимальное значения должны быть достаточно большими, чтобы отображались все данные, и они должны изменяться, если в **CHART** или **GRAPH** добавляются данные, выходящие за пределы текущего диапазона оси. Если ось не указана, алгоритм, используемый приложением EDD для определения минимального и максимального значений оси, не регламентирован и может отличаться в разных приложениях. Разработчик DD должен включать ссылку на **AXIS**, когда требуется больший контроль.

**GRAPHs** и **CHARTs** используют декартову систему координат с осями X и Y. Для данного **CHART** или **GRAPH** ось X является общей для всех отображаемых данных, а для **CHART** ось X всегда представляет время. С **CHART** или **GRAPH** может быть связано одна или несколько осей Y. Если все данные используют общую ось Y, один и тот же конструкт **AXIS** должен быть указан во всех объявлениях данных (**WAVEFORM** или **SOURCE**). На одном **CHART** или **GRAPH** может быть несколько осей Y. В этом случае приложение EDD должно предоставлять индикаторы, позволяющие оператору сопоставить **AXIS** с соответствующим графиком.

{% code title="Lexical structure" %}
```c
AXIS identifier {
    LABEL string-value;
    CONSTANT_UNIT string-value;
    MAX_VALUE min-max-specifier;
    MIN_VALUE min-max-specifier;
    SCALING scaling-specifier;
}
```
{% endcode %}

## 11.7.2 MIN\_VALUE, MAX\_VALUE

**Атрибут MIN\_VALUE** определяет значение, связанное с первой отметкой на оси **AXIS**. Для осей **X\_AXIS** и **Y\_AXIS** первая отметка является крайней левой и крайней нижней соответственно.

**Атрибут MAX\_VALUE** определяет значение, связанное с последней отметкой на оси **AXIS**. Для осей **X\_AXIS** и **Y\_AXIS** последняя отметка является крайней правой и крайней верхней соответственно.

По умолчанию, если **MIN\_VALUE** или **MAX\_VALUE** не определены, значения первой и последней отметки оси **AXIS** определяются на основе данных **WAVEFORM** в **GRAPH**.

Минимальное и максимальное значения оси могут быть получены следующим образом:

* **axis-identifier.MIN\_VALUE**
* **axis-identifier.MAX\_VALUE**
* **axis-identifier.VIEW\_MIN**
* **axis-identifier.VIEW\_MAX**

**VIEW\_MIN** и **VIEW\_MAX** предоставляют доступ к текущим отображаемым минимальному и максимальному значениям на **GRAPH** или **CHART**. Например, их можно использовать внутри метода обновления, чтобы EDD мог управлять данными устройства на основе текущего уровня масштабирования графика.

Если одна и та же ось **AXIS** отображается одновременно на нескольких **CHART** или **GRAPH**, результат обращения к **VIEW\_MIN** или **VIEW\_MAX** не определен и не должен использоваться.

{% code title="Lexical structure" overflow="wrap" %}
```c
MAX_VALUE min-max-specifier;
MIN_VALUE min-max-specifier;
min-max-specifier := [reference | double-constant | float-constant | integer-constant | unsigned-integer-constant]<cond>
```
{% endcode %}

## 11.7.3 SCALING&#x20;

**Атрибут SCALING** определяет способ масштабирования отметок на оси **AXIS**. По умолчанию, если атрибут **SCALING** не указан, ось масштабируется линейно.

Значение **SCALING** остается фиксированным во время отображения **GRAPH** или **CHART**. Масштабирование определяется и фиксируется сразу после выполнения **INIT\_ACTIONS**, но до отображения графика.

Если **GRAPH** или **CHART** закрыть и снова открыть, ось **AXIS** может получить новое значение **SCALING**.

{% code title="Lexical structure" %}
```c
SCALING scaling-specifier;
scaling-specifier := [LINEAR | LOGARITHMIC] <cond>
```
{% endcode %}

Описание атрибутов SCALING приведено в таблице ниже.

<table><thead><tr><th width="145">Значение атрибута</th><th>Описание</th></tr></thead><tbody><tr><td>LINEAR</td><td>Отметки на оси должны масштабироваться линейно.</td></tr><tr><td>LOGARITHMIC</td><td>Отметки на оси должны масштабироваться логарифмически (по основанию 10).</td></tr></tbody></table>

## 11.7.4 CONSTANT\_UNIT&#x20;

**Атрибут CONSTANT\_UNIT** используется, если ось **AXIS** имеет постоянный код единиц измерения. **CONSTANT\_UNIT** задается в виде строки, которая будет отображаться вместе со значениями.

Если у оси **AXIS** не указана постоянная единица измерения, это означает что:

1. либо с ней не связано никаких единиц измерения
2. либо единицы измерения непостоянны

В случаях, когда инженерные единицы измерения могут изменяться, они должны быть представлены с использованием отношения **UNIT**.
