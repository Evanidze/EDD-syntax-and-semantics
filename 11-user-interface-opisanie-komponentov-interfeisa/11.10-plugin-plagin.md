# 11.10 PLUGIN (Плагин)

## 11.10.1 General structure

**PLUGIN** описывает пользовательский плагин интерфейса (User Interface Plug-in, UIP). Это позволяет ссылаться на внешнюю точку входа из DD с использованием UUID.

{% code title="Lexical structure" %}
```c
PLUGIN identifier {
    LABEL string-value;
    HELP string-value;
    UUID uuid-specifier;
    VALIDITY boolean-specifier;
    VISIBILITY boolean-specifier;
}
```
{% endcode %}

## 11.10.2 UUID

**Атрибут UUID** определяет уникальный идентификатор, используемый для идентификации **PLUGIN**. UUID представляет собой универсальный уникальный идентификатор, соответствующий стандарту ISO/IEC 9834-8.

UUID задается 36-символьной строкой, состоящей из:

* 32 шестнадцатеричных цифр (регистр не учитывается)
* Сгруппированных через дефисы в формате: 8-4-4-4-12 цифр

Пример:

```
3F99B900-4D87-101B-99B7-AA0004007F07
```
