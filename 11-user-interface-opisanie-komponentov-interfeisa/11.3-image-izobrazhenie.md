# 11.3 IMAGE (Изображение)

## 11.3.1 General structure

**Базовая конструкция IMAGE** используется для отображения изображений в пользовательском интерфейсе.

{% code title="Lexical structure" %}
```c
IMAGE identifier {
    LABEL string-value;
    HELP string-value;
    LINK reference<cond>;
    PATH string-literal<cond>;
    VALIDITY boolean-specifier;
    VISIBLITY boolean-specifier;
}
```
{% endcode %}

Пример EDD кода для изображения.

```c
IMAGE Sensor_Diagram {
    LABEL "Sensor Diagram";
    HELP "This Diagram shows the sensor characteristic";
    PATH "SenDiaEn.jpg\
          |en zz|SenDiaEn_LowRes.jpg\
          |de|SenDiaDe.jpg\
          |de zz|SenDiaDe_LowRes.jpg";
}
```

**Определение IMAGE** может использоваться для вызова:

* **METHOD** (метода)
* **MENU** с **STYLE DIALOG** или **WINDOW**

с помощью атрибута **LINK**.

Код ниже демонстрирует пример использования атрибута **LINK** в изображении в EDD.

{% code overflow="wrap" %}
```c
MENU {
    ITEMS {
        ...
        Self_Test_Image (INLINE),
        ...
    }
}

IMAGE Self_Test_Image {
    LABEL "Self Test";
    HELP "This Method execute the self test function of the device which needs some time";
    PATH "SelfTestImage.jpg";
    LINK Self_Test_Menu;
}

MENU Self_Test_Menu {
    ...
}
```
{% endcode %}

## 11.3.2 LINK (Ссылка)

**Атрибут LINK** определяет элемент EDD, доступный через IMAGE, что позволяет предоставлять дополнительную информацию об изображении. При выборе IMAGE активируется связанный элемент EDD.

Связанное MENU должно иметь стиль DIALOG или WINDOW, но всегда отображается как DIALOG.

{% code title="Lexical structure" %}
```c
LINK reference<cond>;
```
{% endcode %}

Описание атрибута приведено ниже.

<table><thead><tr><th width="150">Тип значения</th><th>Описание</th></tr></thead><tbody><tr><td>reference&#x3C;cond></td><td><p>Профили связи: CS, FF, GPE, ISA100, PB, PN. </p><p>Ссылка на экземпляр MENU, METHOD или PLUGIN (м.б. задана условно).</p></td></tr><tr><td>reference&#x3C;cond></td><td><p>Профили связи: HART. </p><p>Ссылка на экземпляр MENU, METHOD, PLUGIN или EDIT_DISPLAY.</p></td></tr></tbody></table>

## 11.3.3 PATH (Путь)

**Атрибут PATH** определяет имя файла изображения. Изображения для разных локалей могут быть указаны с использованием техники локализации, аналогичной применяемой для строковых литералов.

Код страны **zz** может использоваться для указания низкокачественной версии изображения, что полезно для приложений EDD, работающих на мобильных устройствах с ограниченной памятью.

**Пример:**

```c
"len|english.jpeg|de|german.jpeg|en zz|english-lowres.jpeg|de zz|german-lowres.jpeg"
```

```
PATH file-name<cond>;
```

Описание атрибута приведено ниже.

<table><thead><tr><th width="108">Тип значения</th><th>Описание</th></tr></thead><tbody><tr><td>file-name</td><td>Строковый литерал, определяющий имя файла изображения (может быть задан условно). Допустимые форматы изображений указаны в Таблице 91.</td></tr></tbody></table>

Описание форматов изображения, которые могут быть использованы в конструкции IMAGE.

<table><thead><tr><th width="108">Формат</th><th>Описание</th></tr></thead><tbody><tr><td>JPG, JPEG</td><td>Формат согласно ISO/IEC 10918</td></tr><tr><td>PNG</td><td>Формат Portable Network Graphics согласно ISO/IEC 15948</td></tr><tr><td>GIF</td><td>Формат Graphics Interchange Format ПРИМЕЧАНИЕ: Некоторые приложения EDD могут не поддерживать анимацию GIF.</td></tr></tbody></table>
