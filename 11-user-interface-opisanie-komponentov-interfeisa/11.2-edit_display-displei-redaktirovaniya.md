# 11.2 EDIT\_DISPLAY (Дисплей редактирования)

## 11.2.1 General structure

**EDIT\_DISPLAY** определяет способ управления данными для целей отображения и редактирования. Он используется для группировки элементов при редактировании. **EDIT\_DISPLAY** отображается аналогично модальному диалогу (т.е. как **MENU** со **STYLE DIALOG**).

Если список действий (**ACTIONS**) для **EDIT\_DISPLAY** является условным, могут возникнуть непредвиденные результаты при изменении этого списка во время выполнения действий из-за условной логики.

{% code title="Lexical structure" %}
```c
EDIT_DISPLAY identifier {
    LABEL string-value;
    HELP string-value;
    DISPLAY_ITEMS { reference+ | reference<cond>+ };
    EDIT_ITEMS { reference+ | reference<cond>+ };
    PRE_EDIT_ACTIONS { actions-specifier };
    POST_EDIT_ACTIONS { actions-specifier };
    VALIDITY boolean-specifier;
    VISIBILITY boolean-specifier;
}
```
{% endcode %}

## 11.2.2 EDIT\_ITEMS (Редактируемые элементы)

**Атрибут EDIT\_ITEMS** определяет набор элементов данных для редактирования пользователем:

* **VARIABLES**
* Отношения **WRITE\_AS\_ONE**
* **BLOCK\_A PARAMETERS**
* Элементы **BLOCK\_A PARAMETERS** (поля RECORD или элементы VALUE\_ARRAY типа BLOCK\_A PARAMETERS)

{% hint style="info" %}
**Примечание:** Конкретные детали отображения и редактирования элементов данных (например, значение по умолчанию, коэффициент масштабирования, диапазон) определяются в определениях каждого соответствующего элемента.
{% endhint %}

Если отношение **WRITE\_AS\_ONE** указано как **EDIT\_ITEM**, пользователь должен проверить все переменные в этом отношении. При этом:

* Не требуется изменять все значения
* Необходимо как минимум убедиться, что текущие значения допустимы

{% code title="Lexical structure" %}
```c
EDIT_ITEMS {reference+ | reference<cond>+}
```
{% endcode %}

## 11.2.3 DISPLAY\_ITEMS (Отображаемые элементы)

**Атрибут DISPLAY\_ITEMS** определяет набор элементов данных, отображаемых пользователю только для ознакомления (без возможности редактирования):

* **VARIABLES**
* **BLOCK\_A PARAMETERS**
* Элементы **BLOCK\_A PARAMETERS** (поля типа RECORD или элементы типа VALUE\_ARRAY соответственно)

{% hint style="info" %}
**Примечание:** Детали отображения элементов данных (например, значение по умолчанию, коэффициент масштабирования, диапазон) определяются в определениях каждого соответствующего элемента.
{% endhint %}

{% code title="Lexical structure" %}
```c
DISPLAY_ITEMS {reference+ | reference<cond>+}
```
{% endcode %}

## 11.2.4 POST\_EDIT\_ACTIONS

**Атрибут POST\_EDIT\_ACTIONS** определяет **METHODs**, которые должны выполняться перед сохранением значений переменных в онлайн или оффлайн набор данных.

**Условия выполнения:**

* Если **EDIT\_DISPLAY** находится в прерванном состоянии (сбой **PRE\_EDIT\_ACTIONS**), **POST\_EDIT\_ACTIONS** не активируются
* Указанные **METHODs** выполняются в порядке их объявления
* При аварийном завершении **METHOD** последующие методы не выполняются

**Обработка ошибок:**\
Если операция **POST\_EDIT\_ACTION** завершилась неудачно:

1. Приложение EDD должно уведомить пользователя о невозможности завершить сохранение
2. Операция сохранения прерывается
3. Пользователь должен иметь возможность повторить попытку сохранения

{% code title="Lexical structure" %}
```c
POST_EDIT_ACTIONS {
    reference<cond> [, reference<cond>]*
}
```
{% endcode %}

## 11.2.5 PRE\_EDIT\_ACTIONS

**Атрибут PRE\_EDIT\_ACTIONS** определяет **METHODS**, которые должны выполняться сразу после отображения **EDIT\_DISPLAY** во время сеанса редактирования.

**Ключевые особенности:**

* **PRE\_EDIT\_ACTIONS** не активируются в сеансе только для чтения
* Методы выполняются последовательно в порядке их объявления
* При незапланированном завершении **METHOD** последующие методы не выполняются
* Приложение EDD должно уведомить пользователя о возникшей проблеме, и элементы становятся недоступными для редактирования

**Порядок выполнения:**\
**PRE\_EDIT\_ACTIONS** для **EDIT\_DISPLAY** выполняются и завершаются **до** запуска **PRE\_EDIT\_ACTIONS** связанных сущностей.

{% hint style="info" %}
**Примечание:**\
**PRE\_EDIT\_ACTIONS** связанных объектов **VARIABLE** активируются и завершаются непосредственно перед началом редактирования (например, при установке курсора в поле). Отображение объектов **VARIABLE** без редактирования не запускает их **PRE\_EDIT\_ACTIONS**.
{% endhint %}

{% code title="Lexical structure" %}
```c
PRE_EDIT_ACTIONS {
    reference<cond> [, reference<cond>]*
}
```
{% endcode %}
