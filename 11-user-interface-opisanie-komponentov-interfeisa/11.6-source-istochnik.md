# 11.6 SOURCE (Источник)

## 11.6.1 General structure

**SOURCE** описывает источник данных для графика **CHART**. Каждый **SOURCE** содержит элементы **MEMBER**, которые определяют отображаемую переменную. Элемент **MEMBER** должен содержать имя и ссылку на числовое значение. Описание и справочная информация являются необязательными строковыми параметрами. На элементы **MEMBER** можно ссылаться из других частей EDD с использованием идентификатора **SOURCE** и имени **MEMBER**, как указано в разделе 16.13.

Переменные, на которые ссылается **SOURCE**, должны быть заданы в методах. Их значения могут быть рассчитаны с использованием переменных устройства и/или локальных переменных.

Если для **SOURCE** определены **INIT\_ACTIONS**, приложение EDD вызывает эти методы вместо непосредственного чтения переменных.

Если для **SOURCE** определены **REFRESH\_ACTIONS**, приложение EDD циклически вызывает эти методы с интервалом **CYCLE\_TIME** вместо чтения переменных.

Для трендовых графиков (**TYPES SCOPE, STRIP** или **SWEEP**) переменная из списка **MEMBER** отображается в зависимости от времени на указанной оси **Y\_AXIS**. Для индикаторных графиков (**TYPES GAUGE, HORIZONTAL\_BAR** или **VERTICAL\_BAR**) переменная отображается с использованием соответствующего индикатора или шкалы.

Если список действий (**ACTIONS**) для **SOURCE** является условным, могут возникать непредвиденные результаты в случае, когда условная логика приводит к изменению этого списка **ACTIONS** во время их выполнения.

Для **SOURCE**, в которых не указаны **LINE\_TYPE** или **LINE\_COLOR**, каждая линия на **CHART** должна визуально отличаться от остальных.

{% code title="Lexical Structure" %}
```c
SOURCE identifier {
    LABEL string-value;
    HELP string-value;
    EMPHASIS boolean-specifier;
    EXIT_ACTIONS { actions-specifier };
    INIT_ACTIONS { actions-specifier };
    LINE_COLOR line-color-specifier;
    LINE_TYPE line-type-specifier;
    MEMBERS { members-specifier };
    REFRESH_ACTIONS { actions-specifier };
    VALIDITY boolean-specifier;
    VISIBILITY boolean-specifier;
    Y_AXIS [reference | reference<cond>];
}
```
{% endcode %}

## 11.6.2 EXIT\_ACTIONS

**Атрибут EXIT\_ACTIONS** определяет **METHODS** (методы), которые выполняются при закрытии **CHART**, содержащего данный **SOURCE**.

Указанные методы выполняются в порядке их перечисления. Если выполнение метода прерывается по незапланированной причине, оставшиеся методы не выполняются.

Если **INIT\_ACTIONS** для **SOURCE** были прерваны, **EXIT\_ACTIONS** не активируются.

{% code title="Lexical Structure" overflow="wrap" %}
```c
EXIT_ACTIONS { actions-specifier }
actions-specifier := [reference<cond> [, reference<cond>]*]? [DEFINITION { compound-statement }]<cond>?
```
{% endcode %}

Атрибуты EXIT\_ACTIONS указаны в таблице 108.

## **11.6.3 INIT\_ACTIONS**

Атрибут INIT\_ACTIONS определяет методы (METHODS), которые выполняются перед первым отображением значения SOURCE на графике CHART. INIT\_ACTIONS запускаются один раз и не выполняются снова, пока содержащий SOURCE график CHART не будет закрыт и открыт заново.

Указанные методы выполняются в порядке их объявления. Если выполнение метода завершается по незапланированной причине, оставшиеся методы не выполняются. Кроме того, приложение EDD не будет отображать значение SOURCE, и EXIT\_ACTIONS не будут активированы, если выполнение метода завершится по незапланированной причине.

Независимо от того, отображаются ли какие-либо источники, график CHART будет отображен (то есть график может быть пустым).

{% code title="Lexical Structure" overflow="wrap" %}
```c
INIT_ACTIONS { actions-specifier }
actions-specifier := [reference<cond> [, reference<cond>]*]? [DEFINITION { compound-statement }]<cond>?
```
{% endcode %}

Атрибуты INIT\_ACTIONS указаны в таблице 108.

## **11.6.4 REFRESH\_ACTIONS**

Атрибут REFRESH\_ACTIONS определяет методы (METHODS), которые выполняются перед первым отображением SOURCE, при изменениях, связанных с X\_AXIS или Y\_AXIS, или если в CHART определен CYCLE\_TIME - каждый раз по истечении CYCLE\_TIME.

Указанные методы выполняются в порядке их объявления. Если выполнение метода завершается по незапланированной причине, оставшиеся методы не выполняются. Кроме того, приложение EDD не будет отображать значение SOURCE, если выполнение метода завершится по незапланированной причине. По истечении CYCLE\_TIME действия REFRESH\_ACTIONS запускаются снова. Если REFRESH\_ACTIONS завершаются успешно, SOURCE на CHART отображается снова.

Независимо от того, отображаются ли какие-либо источники, график CHART будет отображен (то есть график может быть пустым).

Следует избегать встраивания пользовательских интерфейсов в методы REFRESH\_ACTIONS. Поскольку во многих случаях обновления могут происходить часто, пользовательские интерфейсы, встроенные в REFRESH\_ACTIONS, могут создавать значительные неудобства и нарушения работы.

Профиль связи: HART. ⇒ REFRESH\_ACTIONS переменных (VARIABLES), на которые ссылается SOURCE (т.е. MEMBERS), не должны активироваться при обновлении SOURCE.

{% code title="Lexical Structure" overflow="wrap" %}
```c
REFRESH_ACTIONS { [actions-specifier [, actions-specifier]] }
actions-specifier := [reference [, reference]] | [DEFINITION { compound-statement }]
```
{% endcode %}

Атрибуты REFRESH\_ACTIONS указаны в таблице 108.

## **11.6.5 Y\_AXIS**

Атрибут Y\_AXIS определяет способ отображения Y-оси для SOURCE. Каждый SOURCE на CHART использует общую X-ось, основанную на времени, но может иметь собственную Y\_AXIS. По умолчанию, если атрибут Y\_AXIS не указан, отображение Y-оси CHART определяется на основе данных в SOURCE. Когда Y\_AXIS не задан, минимальное и максимальное значения должны быть достаточно большими, чтобы отображались все данные. Минимальное и максимальное значения должны изменяться, если в CHART добавляются данные, выходящие за пределы текущего диапазона оси.

{% code title="Lexical structure" %}
```c
Y_AXIS [reference | reference<cond>] ;
```
{% endcode %}
