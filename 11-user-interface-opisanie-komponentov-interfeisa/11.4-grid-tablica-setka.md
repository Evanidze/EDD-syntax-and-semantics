# 11.4 GRID (таблица, сетка)

## 11.4.1 General structure

СЕТКА описывает матрицу данных, которая будет отображаться приложением EDD. СЕТКА используется для отображения векторов данных вместе с заголовком или описанием данных в этом векторе. Векторы отображаются либо по горизонтали (строки), либо по вертикали (столбцы), как указано в атрибуте ORIENTATION (ОРИЕНТАЦИЯ).

{% code title="Lexical structure" %}
```c
GRID identifier {  
    LABEL string-value ;  
    HELP string-value ;  
    HANDLING handling-specifier ;  
    HEIGHT height-width-specifier ;  
    ORIENTATION orientation-specifier ;  
    VALIDITY boolean-specifier ;  
    VECTORS { vectors-specifier }  
    VISIBILITY boolean-specifier ;  
    WIDTH height-width-specifier ; 
}

```
{% endcode %}

## 11.4.2 ORIENTATION (ориентация)

Атрибут ORIENTATION определяет направление, в котором отображаются векторы. Если атрибут ORIENTATION не указан, по умолчанию используется значение VERTICAL, и векторы отображаются вертикально.

{% code title="Lexical structure" fullWidth="false" %}
```c
ORIENTATION orientation-specifier ;
orientation-specifier := [[HORIZONTAL | VERTICAL] | [HORIZONTAL | VERTICAL] <cond>]
```
{% endcode %}

## 11.4.3 VECTORS (Векторы)

Атрибут VECTORS определяет содержимое ТАБЛИЦЫ. Векторы отображаются в том порядке, в котором они записываются. Для вертикальной таблицы векторы отображаются слева направо. Для горизонтальной таблицы векторы отображаются сверху вниз. Каждый вектор содержит описание, которое содержит метку для вектора, за которой следуют отображаемые данные. Описания, хотя и являются обязательными, могут представлять собой пустую строку, и в этом случае заголовок остается пустым. Если все описания представляют собой пустые строки, то ячейки с заголовками не отображаются.

{% code title="Lexical structure" overflow="wrap" fullWidth="false" %}
```c
VECTORS { vectors-specifier }
vectors-specifier := { [vector-specifier ,]<cond>+ }
vector-specifier := [description [, [string-constant | double-constant | float-constant | integer-constant | unsigned-integer-constant]]+] | [description [, item-reference]+] 1 | [description , array-reference] |

```
{% endcode %}

| Attribute                 | Описание                                                                                                                                                                                      |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| description               | Строка, содержащая краткое описание данных в векторе.                                                                                                                                         |
| item-reference            | Ссылка на экземпляр VARIABLE, IMAGE, элемент экземпляра RECORD, элемент экземпляра VALUE\_ARRAY или элемент экземпляра REFERENCE\_ARRAY.                                                      |
| array-reference           | Ссылка на экземпляр VALUE\_ARRAY или REFERENCE\_ARRAY. Тип VALUE\_ARRAY должен ограничиваться VARIABLE. Тип элемента в REFERENCE\_ARRAY должен ограничиваться ссылками на VARIABLE или IMAGE. |
| string-constant           | Строковая константа или ссылка, которая преобразуется в строку.                                                                                                                               |
| double-constant           | Константа с плавающей точкой двойной точности.                                                                                                                                                |
| float-constant            | Константа с плавающей точкой одинарной точности.                                                                                                                                              |
| integer-constant          | Целочисленная константа.                                                                                                                                                                      |
| unsigned-integer-constant | Целочисленная константа без знака.                                                                                                                                                            |

{% code title="Example" overflow="wrap" fullWidth="false" %}
```c
VARIABLE PeakType
{
    LABEL "Peak Type";
    CLASS DEVICE;
    TYPE ENUMERATED
    {
    { 1, "False Echo"},
    { 2, "Button Echo" },
    { 3, "Unknown" }
    }
}

ARRAY arrPeakType
{
    NUMBER_OF_ELEMENTS 10;
    TYPE PeakType;
}

VARIABLE PeakDistance
{
    LABEL "Peak Distance";
    CLASS DEVICE;
    TYPE FLOAT
    {
    DEFAULT_VALUE 1.0;
    }
}

ARRAY arrPeakDistance
{
    LABEL "Peak Distance";
    NUMBER_OF_ELEMENTS 10;
    TYPE PeakDistance;
}

VARIABLE PeakAmplitude
{
    LABEL "Device Amplitude";
    CLASS DEVICE;
    TYPE FLOAT
    {
    DEFAULT_VALUE 1.0;
    }
}
ARRAY arrPeakAmplitude
{
    LABEL "Peak Amplitudes";
    NUMBER_OF_ELEMENTS 10;
    TYPE PeakAmplitude;
}

MENU DeviceEcho
{
    LABEL "Device Echo";
    ITEMS
    {
    EchoCurve,
    FoundEcho,
    FalseEchos
    }
}

MENU FoundEcho
{
    LABEL "Found echoes";
    STYLE PAGE;
    ITEMS
    {
    GridFoundEcho,
    RegisterFalseEchoes
    }
}

GRID GridFoundEchoes {
    LABEL "All detected echoes are displayed below";
    VALIDITY IF (varModelCode == 4711) { TRUE; } ELSE { FALSE; }
    VECTORS {
        {"Type", arrPeakType},
        {"Distance (m)", arrPeakDistance},
        {"Amplitude (mv)", arrPeakAmplitude}
    }
}
```
